API CMDEB v2

Conjunto Mínimo de Dados da Educação Básica — API de integração para envio, validação, processamento e consulta de dados do CMDEB. Suporta processamento assíncrono por lotes, autenticação via token Bearer, padronização dos payloads e acompanhamento do status de envio.

Base URL /api/v2
Auth Bearer JWT
Formato application/json
Rotas 48
🔐

Autenticação

3 rotas
POST /api/v2/auth/login

Login

Autentica usuário e retorna token JWT que deverá ser utilizado nos demais endpoints para autenticação Bearer.

Credenciais:

  • Username pode ser CPF ou nome de usuário cadastrado
  • Senha deve corresponder à cadastrada no sistema

Resposta:

  • access_token: Token JWT para autenticação nos demais endpoints (deve ser informado no cabeçalho (header): Authorization: Bearer {token})
  • refresh_token: Token para renovar o access_token quando expirar (ver rota /refresh)
  • expires_in: Tempo de validade do access_token (em segundos)
  • refresh_expires_in: Tempo de validade do refresh_token (em segundos)

Erros:

  • 401: Credenciais inválidas (usuário ou senha incorretos)
  • 503: Serviço de autenticação indisponível
  • 500: Erro interno do servidor

Campos do Body

CampoTipoObrigatoriedadeDescrição

password string Obrigatório Senha do usuário
POST /api/v2/auth/refresh 🔐 Bearer Token

Refresh

Renova o access_token a partir de um refresh_token válido.

Use esta rota quando o access_token expirar, evitando um novo login com

usuário e senha. A resposta

traz um novo par access_token/refresh_token que deve substituir o

anterior no cliente.

Resposta:

  • access_token: Novo token JWT de acesso
  • refresh_token: Novo refresh token (substitui o anterior)
  • expires_in: Tempo de validade do access_token (em segundos)
  • refresh_expires_in: Tempo de validade do refresh_token (em segundos)

Erros:

  • 401: Refresh token inválido, expirado ou revogado
  • 503: Serviço de autenticação indisponível
  • 500: Erro interno do servidor

Pé-de-Meia

2 rotas
GET /api/v2/pdm/elegibilidades 🔐 Bearer Token

Listar elegibilidades dos estudantes

Retorna a lista paginada de elegibilidades do Pé-de-Meia para a rede do usuário autenticado.

Filtros disponíveis (mutuamente exclusivos — prioridade: cpf_nis > co_entidade > nenhum):

  • cpf_nis: busca por CPF ou NIS do estudante (fallback automático CPF -> NIS)
  • co_entidade: filtra todos os estudantes de uma instituição pelo código INEP
  • ciclo: restringe ao ano do ciclo informado (ex: 2024)

Sem filtros, retorna todos os registros da rede com paginação.

Parâmetros de Query

ParâmetroTipoObrigatoriedadeDescrição
cpf_nis string Opcional CPF ou NIS do estudante (11 dígitos; preenchimento automático com zeros à esquerda)
co_entidade string Opcional Código da instituição de ensino (INEP)
ciclo string Opcional Ano do ciclo do programa (ex: 2024)
page integer Opcional Número da página default: 1
page_size integer Opcional Itens por página (padrão: 100, máximo: 5000) default: 100
