Como é Feito — Processo Técnico
SERE — Sistema Estadual de Registro Escolar
Gestão: SEED/PR
Tecnologia: PostgreSQL · banco escola · schema sa_escola
Dados fornecidos: escolas (codmec/INEP), turmas (nome, turno, etapa, seriação), alunos (CPF, nascimento, filiação, endereço), matrículas (situação, período letivo), seriação para mapeamento de etapa SGP

Limitação identificada: etapa de ensino SGP não é derivável diretamente — exige CASE WHEN por codseriacao + codcurso.
RCDIGM — Registro de Classe Online
Gestão: Secretaria Municipal de Educação de Campo Largo
Tecnologia: PostgreSQL · banco rcdig · schema public
Dados fornecidos: frequência mensal por aluno (horas ofertadas/presença), notas por disciplina (escala 0–100, convertida para 0–10 ou MB/B/R/I), vínculo professor-turma, lista de professores ativos

Limitação identificada: notas em escala 0–100 exigem conversão; mapeamento coddisciplina → id_sgp_componente requer manutenção contínua.
